# Bundled promotion fallback fonts

Google Fonts repository commit 9710da1eacb3be272583c3224dcb70f9da6eadbb. SIL Open Font License 1.1; accompanying OFL files retain copyright and license. Original variable fonts instantiated at weight 400 with fontTools 4.60.2; full glyph coverage retained. OpenType shaping tables removed for predictable standalone fallback glyph rendering. Roboto PDF embedding subsets used glyphs; fallback fonts embed their bounded complete repertoire because pdf-lib/fontkit subset output drops some CJK glyph outlines (verified by rendered PDF). No external runtime font requests.
